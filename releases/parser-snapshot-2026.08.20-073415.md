# WitFoo Parsers v2026.08.20-073415

**Release Date:** 2026-08-19

## Summary

This release introduces an authoritative fingerprint-probe gate for the auto-parser subsystem, strengthening how parsers validate and route log signals before classification. Vocabulary definitions for Cisco AP-COS and IOS-XE platforms have been expanded, and three parsers — Arista WIPS Sensor, Cisco AP Watchdog, and Cisco OS — have been updated to align with the improved fingerprinting pipeline. The total parser count now stands at 306.

## What's New

### Improvements

- **Authoritative fingerprint-probe gate (auto-parser):** Added a gating mechanism to the auto-parser pipeline that enforces authoritative fingerprint matching before probe-based classification proceeds. This reduces false-positive parser assignments and improves signal fidelity when processing ambiguous or overlapping log formats.
- **Expanded AP-COS / IOS-XE vocabulary:** Enriched the parser vocabulary for Cisco Access Point COS and IOS-XE log formats, enabling more precise field extraction and event categorization across Cisco wireless and network infrastructure logs.

### Bug Fixes

- **Parser corrections for `aristawipssensor`, `ciscoapwatchdog`, and `ciscoos`:** Fixed fingerprint and classification logic in three parsers to align with the new authoritative gate, ensuring these parsers correctly identify and process their respective log formats without misclassification.
