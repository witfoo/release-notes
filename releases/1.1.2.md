# WitFoo Analytics v1.1.2

**Release Date:** 2026-08-13

## Summary

WitFoo Analytics v1.1.2 delivers a major parser expansion (20+ new and corrected parsers), critical security hardening including gRPC and Go toolchain updates, and significant ingestion resilience improvements for Azure and OAuth-based connectors. This release also introduces event-time sanity clamping to prevent mis-bucketed data, fixes a fleet-wide outage class in the image distribution pipeline, and adds telemetry-independent monitoring alarms so operational blindness during data pipeline failures cannot recur.

## What's New

### Features

**Parser Coverage Expansion**
- Added parsers for VMware vSAN EPD, vSAN Cluster Agent, NSX AVIM, Appliance Management, Address Book, vCenter Lookup Service, SSO Tomcat, and Identity STS
- Added parsers for Arista Flow Control, Stealthbits Activity Monitor, and Caprica
- Expanded Cisco Stealthwatch 7.x CEF, NSX netopa, and ESXi/VxRail service coverage
- Cleared a 10-issue parser backlog (#931, #933, #938, #940–#944, #946, #947)

**Event-Time Sanity Clamping**
- Event-time buckets are now accepted only within a `[now − 30 days, now + 1 hour]` window; events outside this range fall back to ingest time, preventing mis-bucketed data from corrupting time-series analytics

**Governance & Compliance (from staging integration)**
- **DCO/CTO Directive Validation** — model directed cyber actions as expected control/config states, validate against real assessment findings and posture data, and produce per-target implemented/partial/not-implemented verdicts with supporting evidence
- **Cross-Cluster Posture Federation** — durable outbox with DDIL-safe backfill, hub receiver with optimistic-concurrency rollups, and a fleet posture trend page at `/ui/reporter/fleet-posture` showing per-edge freshness and honest gap reporting
- **Assessment Correlation Wiring** — PR537's CCI→NIST 800-53/171 correlation is now active in assessment run creation, enabling the scan → findings → controls → assessment flow end-to-end

**WitFoo Console Deployment Option**
- New `console:lite` free-tier SKU enabling Console-only deployments via `wfa configure`
- Licensing API and UI updated to support the Console product type

**Advisory Package-Freshness Check**
- `wfa configure` now checks whether the installed WitFoo package is current using local metadata only (no network calls), with a non-blocking advisory prompt — safe for DDIL environments

**Telemetry-Independent Monitoring**
- New `probe-endpoints` job performs cache-busted external probes of customer-facing endpoints directly from CI runners, defeating Cloudflare Always Online caching
- New `telemetry_silent` absence detection identifies when expected organizations go dark in Loki, preventing the monitor-blindness class that allowed the 2026-07-27 outage to go undetected for 24+ hours

### Improvements

**Ingestion & Connector Resilience**
- Typed OAuth token decoding with auth resilience for Microsoft Sentinel, Microsoft Graph, MDVM, and LimaCharlie connectors — silent auth failures now surface as health events instead of producing zero artifacts indefinitely
- New `decode_error` health code distinguishes provider response decode failures from credential problems, with accurate remediation guidance in both Conductor UI and Analytics UI
- Conductor bumped to 1.8.2 for Azure ingestion resilience hotfix
- Signal-client connector auth suites now run in CI-required contract tests

**Auto-Parser Quality Gates**
- Added Gate 9 (Classification Quality) to the auto-parser generator — rejects `messagetype.Unknown`, `streamname.Unknown`, and minted `UnknownLogXXXXXX` constants; warns on blanket `AuditLog` classifications
- Fixed generator prompt that mandated exact classifications Gate 9 forbids
- Fixed format-aware skip logic that was 100% inert in CI; unknown stream name identifiers now fail Gate 1

**Appliance Operations**
- Docker stack is now reclaimed on role changes, preventing orphaned container sets
- Unused Docker images are pruned after updates and on a 24-hour sweep, reclaiming disk from tier switches and retired containers
- Orphaned NATS JetStream directory trees from re-identified nodes are cleaned up on cold start with fail-closed identity verification
- `/data` partition fallback logging reduced from every 5-minute cycle to once per transition — eliminates hundreds of duplicate WARN lines per journal capture
- Capacity enforcement clamped while measurement basis is in transition

**Image Distribution Hardening (2026-07-27 Outage Class)**
- Registry proxy now forwards all `Accept` header lines to GHCR, fixing deterministic 404s on OCI-typed manifests for Docker clients
- Degraded-token 404 recovery with compare-and-evict cache and per-repo singleflight prevents anonymous-scope tokens from caching permanently
- Container manager no longer strands a node at zero containers when local images exist — proceeds with available images and heals via the 60-second reconcile loop
- Retry errors now preserve the causal error instead of reporting only "max tries exceeded"

**Reporter**
- Fixed demo cost-savings report shipping all-$0 values
- Fixed Reporter mobile layout — hidden redundant icon rail on mobile viewports, resolved Carbon SideNav collision that made drawer submenus untappable, and eliminated horizontal body scrolling
- Reporter navigation collapsed from a flat 29-item list to category-driven tabs with a route-driven tab strip

**Health Dashboard**
- Idle appliances no longer render as RED — `unknown` status correctly maps to a neutral indicator instead of falling through to `danger`
- `created` containers (failed to start) are now visible in the dashboard instead of being silently dropped
- All-`created` container stacks no longer freeze the dashboard on the last healthy reading
- Disk capacity gauge, notifications, banner, and Grafana panel now report on a unified usable-disk basis (Cassandra compaction headroom) with consistent threshold alignment

**Licensing & Support**
- Support job creation no longer requires targeting a specific node when nodes exist — un-targeted jobs dispatch to any live agent
- Node picker now shows recency labels (live / last seen 12m ago / STALE) and warns when listed nodes have been silent for over an hour

**CI/CD & Build**
- Semver tag push restricted to tier branches only, preventing dev pushes from overwriting published release tags
- NATS CLI pinned via `nats-box COPY` instead of `curl | sh` fetch
- Health-check alerts now count unbroken failure streaks instead of failures-in-window
- CI parser propagation matrix corrected; `beta` removed from main→tier propagation
- Bare PAT accepted in `GIT_CREDENTIALS` with Prometheus-key fallback
- Grafana fetcher documentation corrected — one token serves both Loki and Prometheus; what differs is the Basic-auth instance ID per service

**Minimum Hardware Requirements**
- Updated and unified hardware floors across all surfaces (CLI help, documentation, UI): AIO raised to 20 GB / 4 vCPUs; Cassandra-bearing roles receive +4 GB RAM over upstream benchmarks
- `wfa configure --help` now derives floor values from the canonical source instead of maintaining duplicate copies

## Breaking Changes
