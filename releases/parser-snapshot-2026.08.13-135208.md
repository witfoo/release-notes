## What's New

- **Monitor Parsers meta gate:** Added a meta gate for Monitor Parsers, enabling enhanced validation and quality control within the parser pipeline workflow.

### Bug Fixes

- **Zeek/Corelight ISO 8601 connection extraction:** Fixed an issue where Zeek and Corelight `conn` (connection) logs using ISO 8601 formatted timestamps were not being correctly extracted. This resolves potential gaps in network connection telemetry for environments forwarding Zeek or Corelight data with ISO 8601 timestamps rather than epoch format.
