# WitFoo Parsers v2026.08.20-060044

**Release Date:** 2026-08-19

## Summary

This release improves log source identification accuracy for two parsers. The Arista WIPS Sensor parser now correctly claims Arista access-point-mode messages using RFC 3164 syslog framing, and the PAM parser's raw `pam_` fallback matching has been tightened to reduce over-matching. Total parser count stands at 306.

## What's New

### Bug Fixes

- **Arista WIPS Sensor (`aristawipssensor`):** Fixed fingerprinting to properly claim Arista AP-mode log events that use RFC 3164 syslog framing, preventing these events from falling through to less-specific parsers.
- **PAM (`pam`):** Bounded the raw `pam_` fallback regex pattern to prevent overly broad matching, reducing the risk of PAM incorrectly claiming log lines intended for other parsers in the serial pipeline.
