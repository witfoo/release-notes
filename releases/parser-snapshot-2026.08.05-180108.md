# WitFoo Parsers v2026.08.05-180108

**Release Date:** 2026-08-05

## Summary

This release expands the WitFoo Parsers collection to 293 parsers with the addition of two new auto-generated parsers: **Arista Flow Control** and **VMware vSAN EPD**. The VMware vSAN EPD parser was rebuilt on a clean base to ensure a reliable foundation for log processing. Supporting test data and connector updates accompany these additions.

## What's New

- **Arista Flow Control Parser (`aristaflowcontrol`)** — New parser for ingesting and processing Arista flow control log data, enabling security signal extraction from Arista network infrastructure events.
- **VMware vSAN EPD Parser (`vmwarevsanepd`)** — New parser for VMware vSAN Encryption and Protection Domain logs, rebuilt on a clean base for improved reliability and maintainability.

### Improvements
