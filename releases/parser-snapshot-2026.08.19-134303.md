# WitFoo Parsers v2026.08.19-134303

**Release Date:** 2026-08-19

## Summary

This release introduces a new Arista WIPS (Wireless Intrusion Prevention System) sensor parser, expanding the parser library to 306 supported log formats. Additionally, it delivers a fix to the relay-wrapped binary classifier, adds a new processing arm for nginx error logs, and refines vocabulary handling for backup operations.

## What's New

### Features

- **New Arista WIPS Sensor parser** — Added `aristawipssensor` parser to support ingestion and signal processing of Arista Wireless Intrusion Prevention System sensor logs, bringing the total parser count to 306.
- **Nginx error log processing arm** — Extended the `nginx` parser with a dedicated `nginx-error` arm, enabling more accurate fingerprinting and classification of nginx error log events separate from access logs.

### Improvements

- **Backup vocabulary enrichment** — Updated `backup.sh` vocabulary definitions to improve signal categorization and context for backup-related log events.
- **Connector updates** — Modifications to `connector.go` to support evolving ingestion requirements.
- **Test data updates** — Expanded `testdata` to cover new and modified parser scenarios.

### Bug Fixes

- **Relay-wrapped binary classifier fix** — Corrected an issue in the binary classifier that improperly handled relay-wrapped log formats, improving classification accuracy for logs forwarded through relay infrastructure (e.g., syslog relays).
