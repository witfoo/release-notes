# WitFoo Parsers v2026.08.13-152011

**Release Date:** 2026-08-13

## Summary

This release delivers an audit-driven parser expansion covering Cisco Stealthwatch 7.x CEF log ingestion, VMware NSX network operations telemetry, and broadened VMware ESXi/VxRail service coverage. A detector fix is also included to improve signal accuracy. The total parser count has grown to 299.

## What's New

### Features

- **Cisco Stealthwatch 7.x CEF support** — Added parser coverage for Cisco Stealthwatch 7.x logs in Common Event Format (CEF), enabling ingestion and normalization of network visibility and threat detection events.
- **VMware NSX Network Operations (netopa) parser** — New parser for VMware NSX network operations logs, expanding coverage of NSX distributed networking telemetry.
- **VMware ESXi / VxRail service coverage expansion** — Extended the VMware ESXi parser to cover additional VxRail service log patterns, improving signal extraction from hyperconverged infrastructure environments.

### Improvements

- **VMware NSX Firewall parser updates** — Refined parsing logic for VMware NSX Firewall logs to align with the broader NSX audit batch.
- **VMware Reverse HTTP Proxy (rhttpproxy) parser updates** — Improved coverage for VMware reverse HTTP proxy logs, capturing additional event patterns from ESXi management plane traffic.
- **Connector module updates** — Updated the core connector logic (`connector.go`) to support the new and revised parser pipelines introduced in this batch.
- **Test data additions** — Expanded test data corpus to validate the new and updated parsers across Stealthwatch, NSX, and ESXi log formats.

### Bug Fixes

- **Detector fix** — Corrected a detection logic issue identified during the audit batch review, improving the accuracy of signal classification for affected log sources.
