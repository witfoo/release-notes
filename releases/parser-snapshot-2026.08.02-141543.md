# WitFoo Parsers v2026.08.02-141543

**Release Date:** 2026-08-02

## Summary

This release expands VMware infrastructure coverage with two new parsers for VMware NSX components and widens fingerprint matching for two existing VMware parsers. The total parser count increases to 287, strengthening log ingestion capabilities across VxRail, ESXi, and NSX environments critical to enterprise virtualization security monitoring.

## What's New

### Features

- **VMware NSX Nest DB Parser (`vmwarensxnestdb`)** — New parser for VMware NSX Nest database logs, enabling security signal processing from NSX distributed database components
- **VMware NSX SFH Health Check Parser (`vmwarensxsfhc`)** — New parser for VMware NSX Service Fabric Host health check logs, providing visibility into NSX control plane health events

### Improvements

- **VMware ESXi Parser (`vmwareesxi`)** — Widened regex fingerprints to capture additional ESXi log formats, improving match coverage across VxRail and standalone ESXi deployments
- **VMware vCenter Parser (`vmwarevcenter`)** — Widened regex fingerprints to recognize broader vCenter log variations, reducing unmatched log volume from vCenter environments
- **Connector updates (`connector.go`)** — Updated connector logic to support the new VMware NSX parser integrations
- **Test data (`testdata`)** — Added and updated test fixtures for all new and modified parsers
